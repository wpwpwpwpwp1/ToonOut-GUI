# 010. GPU 가속 팩 저장 위치 선택

## 문제

GPU 가속 팩은 설치 중 약 8.4GB의 여유 공간이 필요하지만 이전 버전은 사용자 C
드라이브의 `%LOCALAPPDATA%`에만 설치했다. C 드라이브 공간이 부족한 사용자는 다른
드라이브를 사용할 방법이 없었다.

## 검토한 선택지

- 기본 위치만 유지하고 사용자가 Windows 링크를 직접 만들게 한다.
- 설치 전 위치만 선택하고 기존 팩은 삭제 후 다시 받게 한다.
- 설치 위치를 저장하고 기존 팩도 검증하며 이동한다.

## 결정

GPU 팩의 정확한 폴더를 `QSettings`에 저장한다. 기본 위치는 그대로 유지하되 처리
장치 창에서 비어 있고 쓰기 가능한 폴더를 선택할 수 있게 한다. 이미 설치된 팩은
같은 드라이브에서 디렉터리를 이동하고, 다른 드라이브에서는 새 위치로 복사한 뒤
파일을 검증하고 기존 팩을 삭제한다.

## 이유

기존 사용자의 경로는 바꾸지 않으면서 큰 GPU 팩을 여유 있는 드라이브에 둘 수 있다.
Windows 링크에 의존하지 않고 앱이 실제 위치를 알고 있어 업데이트·검사·삭제도 같은
경계를 계속 사용한다.

## 결과와 제약

- 새 위치는 사용자 파일을 보호하기 위해 비어 있는 폴더여야 한다.
- 다른 드라이브로 이동할 때는 새 팩의 논리 크기만큼 추가 여유 공간이 필요하다.
- 복사와 검증이 끝나기 전에는 기존 팩과 설정을 유지한다.
- 새 위치 적용 후 기존 폴더 삭제가 실패하면 새 팩을 사용하고 사용자에게 남은 폴더를
  직접 확인하도록 안내한다.
