# 007. 자동 업데이트 릴리스 채널

## 문제

설치된 ToonOut은 GitHub의 `releases/latest/download/update.json`을 확인한다. GitHub의
latest 릴리스 API는 사전 릴리스를 제외하므로, 기존 unsigned beta 릴리스만 있을 때는
설치본이 새 버전을 발견할 수 없다.

## 검토한 선택지

- Authenticode 인증서를 준비한 뒤 서명된 정식 릴리스만 게시한다.
- 앱의 업데이트 주소를 사전 릴리스 전용 주소로 바꾼다.
- 설치 파일은 서명되지 않았더라도 manifest 서명과 테스트를 통과한 빌드를 정식
  릴리스 채널에 게시한다.

두 번째 선택지는 이미 설치된 앱의 주소를 바꿀 수 없어 첫 업데이트 문제를 해결하지
못한다. 첫 번째 선택지는 가장 좋은 장기 선택이지만 현재 인증서가 없어 즉시 적용할 수
없다.

## 결정

Authenticode 인증서가 없을 때도 전체 테스트를 통과하고 Ed25519로 서명된
`update.json`을 가진 빌드는 정식 릴리스 채널에 게시한다. 설치 파일 제목에는
`unsigned`를 표시한다.

## 결과와 제약

- 기존 설치본이 `releases/latest`를 통해 업데이트를 발견할 수 있다.
- manifest 변조는 앱에 포함된 공개키로 검증한다.
- 설치 프로그램 자체에는 Windows 게시자 신원이 없으므로 SmartScreen 경고가 나타날
  수 있다.
- Authenticode 인증서를 마련하면 같은 채널에서 EXE와 설치 프로그램까지 서명한다.
