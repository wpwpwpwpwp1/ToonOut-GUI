# GPU 런타임 디스크 점유량 절감

## 문제

선택형 NVIDIA GPU 팩의 논리 크기는 5.12GB이고 그중 약 95%가 PyTorch와 CUDA
파일이다. 분할 배포본을 설치할 때 3.27GB 임시 ZIP까지 다시 만들기 때문에 사용자와
개발자 모두 큰 상시·임시 디스크 공간을 부담했다.

## 검토한 선택지

- 현재 PyTorch/CUDA 팩을 그대로 유지한다.
- PyInstaller 수집 항목과 작은 Python 패키지를 더 제외한다.
- ncnn/Vulkan 등 더 작은 추론 런타임으로 즉시 교체한다.
- 현재 추론 경계를 유지하면서 분할본을 직접 읽고 설치 파일을 투명 압축한다.

작은 Python 패키지는 전체 팩에서 차지하는 비율이 낮아 충분한 절감이 되지 않는다.
추론 런타임 교체는 장기적으로 검토할 가치가 있지만 모델 변환, 결과 정확도, 성능과
지원 GPU 범위를 별도로 검증해야 한다.

## 결정

분할 파일을 seek 가능한 하나의 읽기 스트림으로 제공해 임시 ZIP 없이 `zipfile`이
직접 설치하도록 한다. 설치 파일 검증이 끝난 뒤 Windows `compact.exe`의 LZX 실행
파일 압축을 적용한다. 압축을 지원하지 않는 파일 시스템에서는 설치를 실패시키지
않고 일반 파일을 유지한다.

빌드 스크립트는 분할본 생성이 성공하면 중복 원본 ZIP과 GPU worker 중간 빌드 폴더를
기본 삭제한다. 디버깅에 필요한 경우에만 명시적인 보관 옵션을 사용한다.

## 결과와 제약

- 현재 GPU 팩의 실제 점유량은 5.12GB에서 3.29GB로 35.8% 줄었다.
- 설치 중 3.27GB 임시 조립 ZIP이 더 이상 필요하지 않다.
- 앱은 Windows API로 압축 후 실제 디스크 점유량을 표시한다.
- 압축된 CUDA worker의 모델 로드와 실제 이미지 한 장 추론을 확인했다.
- 비 NTFS 드라이브에서는 최대 5.12GB를 계속 사용할 수 있다.
- 더 큰 절감을 원하면 별도의 추론 런타임 전환 실험과 품질·성능 측정이 필요하다.
