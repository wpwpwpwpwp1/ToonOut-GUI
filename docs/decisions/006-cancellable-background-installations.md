# 취소 가능하고 다시 열 수 있는 설치 작업

## 문제

모델 설치 창을 닫으면 설치는 계속되지만 진행 상태를 다시 볼 수 없었고, 모델 설치의 취소 버튼은 비활성화되어 있었다. GPU 가속 팩 설치도 긴 검증·압축 해제·파일 검증 단계 동안 창과 작업 수명이 결합되어 같은 문제가 생길 수 있었다.

## 검토한 선택지

- 설치 창을 닫지 못하게 유지한다.
- UI 스레드와 같은 프로세스의 작업 스레드에서 취소 플래그만 확인한다.
- 설치 작업을 창과 분리하고, 모델은 별도 프로세스에서 설치하며 GPU 팩은 안전한 파일 경계마다 협력적으로 취소한다.

## 결정

설치 작업 상태는 메인 창이 소유하고 설치 창은 그 상태를 보여주는 뷰로만 사용한다. 창을 닫아도 작업은 계속되며 헤더 상태 버튼으로 같은 설치 창을 다시 연다.

모델 설치는 별도 프로세스에서 실행한다. 다운로드 중 취소하면 프로세스를 종료할 수 있으므로 큰 단일 다운로드가 끝날 때까지 기다리지 않는다. 상태는 임시 JSON-lines 파일로 부모 프로세스에 전달한다.

GPU 팩 설치는 기존 파일을 마지막 원자적 교체 전까지 건드리지 않는 staging 구조를 유지한다. 팩 검증, 압축 해제, 설치 파일 검증, NTFS 압축 단계에서 취소를 확인하고 취소 시 staging 폴더를 정리한다.

## 결과와 제약

- 설치 창 닫기와 실제 설치 취소가 서로 다른 동작이 된다.
- ToonOut 종료 시 진행 중인 설치를 취소할지 확인하고, 취소 정리가 끝난 뒤 종료한다.
- 모델 설치가 완료된 뒤 실제 이미지 처리를 시작할 때 모델을 현재 프로세스에 한 번 다시 로드한다.
- 강제 전원 종료처럼 프로세스가 정리 코드를 실행할 수 없는 상황은 완전히 복구할 수 없지만, Hugging Face의 부분 다운로드는 다음 설치에서 재사용할 수 있다.
