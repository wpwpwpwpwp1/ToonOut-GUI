# ToonOut 배포 요구 사양

이 문서는 `0.1.12` Windows 배포판의 지원 기준과 실제 배포 용량을 기록한다.
용량은 2026-07-21 로컬 릴리스 빌드와 실제 CPU/GPU 추론으로 확인했다.

## 사용자에게 안내할 사양

| 항목 | CPU 기본판 | NVIDIA GPU 가속 사용 시 |
|---|---:|---:|
| 운영체제 | Windows 10/11 64-bit | Windows 10/11 64-bit |
| 메모리 | 8GB 최소, 16GB 권장 | 16GB 권장 |
| 그래픽 | 필요 없음 | CUDA 12.8을 지원하는 최신 드라이버의 NVIDIA GPU, VRAM 6GB 이상 권장 |
| 첫 설치 전 빈 디스크 | 3GB 이상 | GPU 팩 다운로드와 새 런타임을 함께 둘 약 8.4GB |
| 인터넷 | 첫 모델 설치에 필요 | 모델과 GPU 팩 다운로드에 필요 |

CPU만 사용해도 모든 기능을 쓸 수 있다. Python, PyTorch, CUDA Toolkit은 사용자가
별도로 설치하지 않는다. AMD·Intel GPU 가속은 현재 지원하지 않는다. GPU 드라이버가
맞지 않거나 팩 실행에 실패하면 앱에서 CPU로 전환할 수 있다.

RAM과 VRAM 수치는 현재 추론 크기에 대한 보수적인 공개 베타 지원 기준이다. 초대형
원본은 디코딩 시 추가 메모리를 사용한다. 앱은 PNG, JPG/JPEG, WEBP를 지원하고,
한 장이 100,000,000 픽셀을 넘으면 추가하지 않는다.

## 확인된 저장 공간

- CPU 앱 본체: 673,263,892 bytes (642.07MiB, 0.63GiB)
- 깨끗한 모델 설치: 886,158,184 bytes (845.11MiB, 약 0.89GB)
- CPU 앱 + 모델 정상 사용 상태: 약 1.56GB (1.45GiB)
- GPU 팩 다운로드: 3,265,060,719 bytes (3.27GB, 3.04GiB)
- GPU 팩 설치 후 논리 크기: 5,115,666,917 bytes (5.12GB, 4.76GiB)
- NTFS LZX 적용 후 실제 디스크 점유량: 3,285,587,818 bytes (3.29GB, 3.06GiB)
- GPU 정상 사용 상태(앱 + 모델 + 압축된 팩): 약 4.85GB (4.52GiB)

분할 GPU 팩은 조각을 하나의 임시 ZIP으로 다시 만들지 않고 직접 검증하고 읽는다.
다운로드 조각 3.27GB와 압축 전 새 런타임 5.12GB가 설치 중 잠시 함께 존재하므로,
현재 측정 팩은 처음 설치와 업데이트 모두 약 **8.4GB 여유 공간**이 필요하다. 앱은
고정 10GB를 요구하지 않고 다운로드 전 3.27GB, 압축 해제 전 5.12GB를 각 단계에서
실제로 확인한다. 설치된 파일은
Windows LZX로 투명 압축하며, 현재 빌드에서는 실제 점유량이 35.8% 줄었다. NTFS가
아니거나 운영체제가 압축을 지원하지 않으면 설치는 중단하지 않고 5.12GB 일반
형식으로 유지한다. 앱은 고정된 GPU 팩 릴리스에서 분할 파일을 자동으로 받고, 설치가
끝나거나 취소·실패하면 임시 `.partNN` 및 `.parts.json`을 자동으로 정리한다.
비정상 종료로 정리가 중단돼도 다음 실행에서 종료된 프로세스의 임시 다운로드,
압축 해제, 이전 버전 백업만 식별해 제거한다.

## 첫 실행 네트워크와 개인정보

모델이 없으면 약 0.89GB를 Hugging Face에서 한 번 내려받는다. 이후에는 선택한 모델
폴더를 재사용한다. GPU 가속 팩 설치 버튼은 실행 중인 ToonOut 버전과 호환되는
Release의 manifest와 모든 조각을 자동으로 내려받아 크기와 SHA-256을 검증한다.
이미지 추론과 결과 저장은 로컬에서 이루어지며 이미지 자체를 원격 서버로 업로드하지
않는다. 자동 업데이트 확인과 모델/GPU 팩 다운로드에만 네트워크를 사용한다.

## 배포자가 아직 확인해야 할 호환성 범위

릴리스 후보마다 Windows 10과 Windows 11의 깨끗한 사용자 계정에서 설치, 첫 모델
설치, CPU 1장 처리, GPU 팩 설치와 GPU 1장 처리, 업데이트, 제거를 smoke test한다.
현재 개발 컴퓨터에서는 패키지 UI 시작, CPU 실제 추론, LZX 압축된 CUDA 12.8 GPU
worker의 실제 추론을 확인했다. Windows on ARM, 기업 프록시, 원격 데스크톱 GPU,
6GB 미만 VRAM은 지원 보장 범위가 아니다.
