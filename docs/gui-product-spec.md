# ToonOut GUI 소개 스펙

## 문서 정보

- 대상 버전: ToonOut Desktop `0.1.11`
- 대상 운영체제: Windows 10/11 64-bit
- 문서 목적: 앱 소개, 배포 페이지, 사용자 안내에서 기능과 용량을 일관되게 설명한다.

## 한 줄 소개

**ToonOut은 여러 애니메이션 이미지를 한 번에 불러와 배경을 제거하고, 투명 PNG로 바로 저장하는 로컬 Windows 앱이다.**

## 사용자에게 전달할 핵심 가치

1. **여러 장을 한 번에 처리한다.** 파일 또는 폴더를 추가하고 대기열 전체를 연속 처리한다.
2. **이미지가 PC 밖으로 나가지 않는다.** 모델 다운로드와 업데이트 확인을 제외한 이미지 처리는 로컬에서 이루어진다.
3. **완료한 결과를 바로 보존한다.** 이미지 한 장이 끝날 때마다 지정한 폴더에 투명 PNG로 저장한다.
4. **CPU로 바로 시작하고 GPU는 선택한다.** NVIDIA GPU가 있는 사용자만 현재 앱에 맞는 가속 팩을 버튼 한 번으로 설치한다.
5. **큰 파일의 위치와 용량을 사용자가 관리한다.** 모델 저장 위치를 고를 수 있고 모델·GPU 팩을 앱에서 이동하거나 삭제할 수 있다.

## 대표 소개 문안

ToonOut은 ToonOut/BiRefNet 모델로 애니메이션 캐릭터와 오브젝트의 배경을 제거하는
배치 중심 GUI다. 이미지를 창에 끌어 놓고 저장 위치를 선택한 뒤 배경 제거를 시작하면,
각 결과를 원본 크기의 투명 PNG로 즉시 저장한다. 원본 이미지와 기존 출력은 덮어쓰지
않으며, 일부 이미지가 실패해도 완료된 결과는 그대로 남는다. 모든 추론은 사용자의
PC에서 실행되며 CPU 처리를 기본 제공하고 호환되는 NVIDIA GPU 가속을 선택적으로
추가할 수 있다.

## 기본 사용 흐름

1. `이미지 추가`, `폴더 추가` 또는 창 전체 드래그 앤 드롭으로 이미지를 대기열에 넣는다.
2. 목록에서 썸네일, 파일명, 이미지별 처리 상태를 확인한다.
3. 결과를 저장할 폴더와 필요하면 출력 이름의 접두사·접미사를 정한다.
4. `배경 제거 시작`을 누른다. 모델 준비와 현재 처리 항목, 완료·실패 개수가 표시된다.
5. 원본, 결과, 비교 보기로 투명 배경 결과를 확인한다.
6. 실패한 항목만 다시 시도하거나 목록에서 제거한다.
7. 작업이 끝나면 `저장 폴더 열기`로 결과를 확인한다.

처리 중에도 새 이미지나 폴더를 대기열에 추가할 수 있다. 일시정지와 중지는 현재
이미지 처리가 안전하게 끝난 다음 적용되며, 이미 저장된 결과는 유지된다.

## GUI 구성

### 상단 상태 영역

- 이미지·폴더 추가
- CPU/GPU 처리 상태와 가속 팩 관리
- 항상 표시되는 업데이트 확인 버튼과 확인·다운로드·설치 상태
- 모델 설치 상태와 저장 위치 관리

### 왼쪽 대기열

- 안정적인 내부 ID를 사용하는 이미지 목록
- 준비, 처리 중, 완료, 실패, 취소 상태
- 다중 선택, 선택 항목 재시도·제거, 전체 비우기
- 읽을 수 없거나 지원하지 않는 파일의 개별 제외 안내

### 오른쪽 미리보기

- 원본, 결과, 비교 보기
- 투명도를 보여 주는 체크무늬 배경
- 휠 확대·축소, 드래그 이동, 100%, 화면 맞춤
- 선택한 항목의 구체적인 오류 표시

### 하단 작업 영역

- 전체 및 이미지별 진행 상태
- 출력 폴더와 파일 이름 형식
- 절약, 균형, 최대 성능, 사용자 지정 성능 모드
- 일시정지, 재개, 중지, 새 작업, 저장 폴더 열기

## 파일과 출력 규칙

- 입력 형식: PNG, JPG/JPEG, WEBP
- 최대 입력 크기: 이미지당 100,000,000 픽셀
- 출력 형식: 원본 크기를 유지한 투명 PNG
- 기본 출력 이름: `원본파일명.png`
- 이름 충돌: 먼저 `_no_bg`, 이후 `_2`, `_3`처럼 번호를 붙여 기존 파일을 보호한다.
- 사용자 지정 이름: 원본 이름 앞뒤에 접두사와 접미사를 지정할 수 있다.
- EXIF 방향을 적용하고 실제 파일 내용을 검사한 뒤 처리한다.

## 용량 스펙

용량은 `0.1.1` 릴리스 빌드와 실제 CPU/GPU 추론으로 확인한 값이다. 사용자가 받는
다운로드 크기와 설치 후 디스크 점유량은 서로 다르므로 반드시 구분해서 안내한다.

| 구분 | 다운로드 또는 설치 크기 | 사용자 안내 |
|---|---:|---|
| Windows 설치 프로그램 | 176,534,922 bytes, 약 0.18GB | 앱을 처음 설치할 때 다운로드 |
| 설치된 CPU 앱 본체 | 약 0.67GB | 모든 사용자에게 필요 |
| ToonOut 모델 | 약 0.89GB | 첫 모델 설치 때 한 번 다운로드 |
| CPU 정상 사용 상태 | 약 1.56GB | 앱 본체와 모델을 합친 상시 점유량 |
| NVIDIA GPU 팩 다운로드 | 약 3.27GB | GPU 가속을 선택한 사용자만 필요 |
| GPU 팩 논리 크기 | 약 5.12GB | 압축 전 파일 크기의 합계 |
| GPU 팩 실제 점유량 | 약 3.29GB | NTFS LZX 압축 적용을 확인한 값 |
| GPU 정상 사용 상태 | 약 4.85GB | 앱, 모델, 압축된 GPU 팩의 상시 점유량 |

### 권장 빈 공간

- CPU만 사용: 첫 설치 전 **3GB 이상**
- NVIDIA GPU 팩 설치 또는 업데이트: 현재 팩 기준 약 **8.4GB**

GPU 팩 설치 중에는 3.27GB 다운로드 조각과 새 런타임 파일이 잠시 함께 존재한다.
앱은 분할 파일을 하나의 임시 ZIP으로 다시 만들지 않고 직접 읽어 불필요한 3.27GB
복제를 방지한다. 설치가 끝나거나 취소·실패하면 내려받은 `.partNN` 파일과
`.parts.json`을 자동으로 정리한다. 다운로드와 새 런타임에 필요한 공간은 각 단계의
검증된 실제 크기로 검사하며, 비정상 종료가 남긴 임시 폴더는 소유 프로세스가
종료된 것을 확인한 뒤 정리한다.

설치된 GPU 팩은 지원되는 NTFS 드라이브에서 Windows LZX 압축을 적용한다. 측정한
빌드에서는 GPU 팩의 실제 점유량이 5.12GB에서 3.29GB로 35.8% 줄었다. 압축을
지원하지 않는 파일 시스템에서는 기능을 유지하기 위해 최대 5.12GB의 일반 파일로
설치될 수 있다. GUI에는 논리 크기가 아니라 운영체제가 보고한 실제 디스크 점유량을
표시한다.

### 저장 위치와 삭제

- 모델 기본 위치: `%LOCALAPPDATA%\ToonOut\models`
- GPU 팩 기본 위치: `%LOCALAPPDATA%\ToonOut\runtimes\nvidia-gpu`
- 첫 모델 설치 전에 다른 드라이브나 쓰기 가능한 폴더를 선택할 수 있다.
- 설치된 모델은 GUI에서 다른 위치로 옮기거나 삭제할 수 있다.
- GPU 팩도 GUI에서 삭제할 수 있으며 모델과 사용자 이미지는 건드리지 않는다.

### 설치 작업과 창

- GPU 설치 버튼은 앱에 고정된 GPU 팩 Release에서 검증값과 worker protocol이
  일치하는 NVIDIA 팩을 자동으로 선택한다. 앱 패치 버전은 같은 팩을 재사용한다.
- 모델과 GPU 가속 팩 설치 창은 설치 중 닫을 수 있으며, 설치는 백그라운드에서 계속된다.
- 헤더의 모델 또는 GPU 상태 버튼은 설치 중 상태를 표시하고 설치 창을 다시 연다.
- 설치 창은 실제 작업 진행에 맞춰 막대와 `[현재 단계] n%` 형식의 텍스트를 함께 표시한다.
- 설치 창의 취소 버튼은 실제 설치 작업을 중단한다. ToonOut 종료 시에도 진행 중인 설치를 취소할지 확인한다.
- 취소된 GPU 설치는 임시 파일을 정리하고 기존에 설치된 호환 팩이 있으면 그대로 유지한다.

## 지원 환경

| 항목 | CPU 기본판 | NVIDIA GPU 가속 |
|---|---|---|
| 운영체제 | Windows 10/11 64-bit | Windows 10/11 64-bit |
| RAM | 최소 8GB, 16GB 권장 | 16GB 권장 |
| GPU | 필요 없음 | CUDA 12.8 지원 NVIDIA GPU |
| VRAM | 해당 없음 | 6GB 이상 권장 |
| 별도 설치 | Python·PyTorch 불필요 | Python·PyTorch·CUDA Toolkit 불필요 |

AMD·Intel GPU 가속과 Windows on ARM은 현재 지원 보장 범위가 아니다. NVIDIA
드라이버나 GPU 팩에 문제가 생기면 같은 앱에서 CPU 처리로 전환할 수 있다.

## 개인정보와 네트워크

- 입력 이미지와 결과 이미지는 원격 서버에 업로드하지 않는다.
- 이미지 픽셀, 개인 경로, 인증 정보를 원격 로그로 보내지 않는다.
- 인터넷은 첫 모델 다운로드, 선택형 GPU 팩 다운로드, 자동 업데이트 확인에 사용한다.
- 모델은 약 0.89GB를 한 번 받은 뒤 선택한 로컬 폴더에서 재사용한다.

## 오류와 복구 원칙

- 한 이미지의 실패가 나머지 배치를 중단시키지 않는다.
- 완료된 이미지는 즉시 저장되어 중지하거나 앱을 닫아도 남는다.
- 실패 항목에는 가능한 원인을 표시하고 해당 항목만 다시 시도할 수 있다.
- 모델·GPU 팩은 크기와 SHA-256을 검증한 뒤 설치한다.
- GPU 팩이 없거나 호환되지 않아도 CPU 기능은 계속 사용할 수 있다.
- 원본과 기존 결과 파일을 조용히 덮어쓰지 않는다.

## 공개 시 주의할 표현

- 실제 하드웨어별 측정 없이 구체적인 처리 속도나 GPU 배수를 약속하지 않는다.
- `5.12GB`는 GPU 팩의 논리 크기이고 `3.29GB`는 NTFS 압축 후 측정값임을 구분한다.
- GPU 설치에는 순간적으로 더 많은 공간이 필요하므로 상시 점유량만 보고 안내하지 않는다.
- 현재 Windows 설치 프로그램은 코드 서명되지 않은 베타이므로 배포 페이지에 이를 표시한다.
- ToonOut 코드와 가중치는 MIT, 학습 데이터셋은 별도의 CC BY 4.0 라이선스임을 밝힌다.
